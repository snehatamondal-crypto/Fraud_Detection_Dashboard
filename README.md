Fraud Detection Analytics Dashboard

📌 Project Overview

This project focuses on analyzing fraudulent transactions using Microsoft Power BI. The main objective is to identify suspicious transactions, understand fraud patterns, and visualize transaction insights through an interactive dashboard.

🎯 Project Objectives

- Analyze transaction data.
- Identify fraudulent transactions.
- Understand fraud patterns and trends.
- Compare fraudulent and legitimate transactions.
- Create an interactive dashboard using Power BI.

📂 Dataset

- File Name: Fraud_Detection_Analytics_Project.xlsx
- Data Format: Excel (.xlsx)
- Total Records: 1500 Transactions
- Data Type: Raw Transaction Data

🛠️ Tools & Technologies

- Microsoft Excel – Data Storage
- Microsoft Power BI – Data Visualization and Dashboard Development
- Power Query – Data Transformation and Cleaning
- DAX – Calculations and Measures

📊 Dashboard Features

- Total Transactions
- Fraudulent Transactions
- Fraud Rate
- Total Transaction Amount
- Fraud by Transaction Type
- Fraud by Location
- Fraud Trends
- Interactive Filters and Slicers

🔍 Key Insights

The dashboard helps users understand:

- Which transaction types have more fraud cases.
- How fraud cases vary across locations.
- Patterns in fraudulent transactions.
- Differences between fraudulent and legitimate transactions.

🚀 Conclusion

This project demonstrates the use of Excel and Power BI for transaction data analysis and fraud pattern visualization. It helps transform raw transaction data into meaningful business insights.
